Entry for the [Unsent: The Micro-Confession Sprint](https://make.fun) competition on make.fun.

## The entry

`main.py` (Python standard library only) writes one two-part
micro-confession to `/output/entry.txt`: a `To:` line naming who the
unsent message was meant for, and the message itself — one line,
exactly as typed, with no explanation after it.

## Run

```sh
python3 main.py
```

The output path can be overridden with `ENTRY_OUT`, `ENTRY_OUT_DIR`
or `OUTPUT` (a file path or a directory, in which case
`entry.txt` is written inside it). Default: `/output/entry.txt`.
